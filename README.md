# Move Zeroes - Java

## Problem Statement

Given an integer array, move all zeroes to the end of the array
while maintaining the relative order of the non-zero elements.

## Example

Input:

[0, 1, 0, 3, 12]

Output:

[1, 3, 12, 0, 0]

## Explanation

The non-zero elements are moved to the beginning:

1, 3, 12

The remaining positions are filled with zeroes.

## Approach

Use an index to place all non-zero elements at the beginning.

After placing all non-zero elements, fill the remaining positions
with zeroes.

## Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)

## Language

Java

## Algorithm

Two Pointer / Array
